# Dayly Anti-Patterns

Do not:

- rewrite the whole app
- replace Expo Router
- replace the theme system
- add Redux/Zustand unless truly needed
- add a heavy 3D engine
- create massive components
- hardcode colours when theme colours exist
- implement social before the core XP/reward loop
- implement geofencing before deployment basics
- create placeholder features that do nothing
- break Supabase auth
- expose secrets
- ignore RLS
- make the UI childish/neon
- change the app’s premium dark/grey identity
